
# 📅 Age Calculator

This is a simple and interactive Age Calculator web application where users can enter or pick their date of birth to calculate their exact age.
Built using HTML, CSS, and JavaScript.

---

## ✨ Features
- User can **type** their Date of Birth **or** **select** it using a calendar picker.
- Clean and **responsive design**.
- **Smooth animations** for better user experience.
- **Error handling** for invalid dates (with shake animation!).
- Displays accurate **current age** in years.

1. Clone the repository:
   ```bash

   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter or pick your birth date and hit **Calculate Age**!
